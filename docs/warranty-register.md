# 保修与发票登记 / Warranty & Invoice Register

大家电与贵重物品一机一行，下单后立即登记。建议打印后贴在文件袋上，同时保留电子版：平台订单号、发票号、安装工单号任一缺失，售后都可能要求补材料。

One row per major appliance or valuable item — log it right after ordering. Print a copy for your document folder and keep the digital version too: missing the platform order number, invoice number or installation ticket can all delay a service claim.

## 填写说明 How to Fill In

| 列 Column | 填写要点 What to Enter |
| --- | --- |
| 分类 Category | 与采购清单分类一致，如"大家电" Use the same category as the checklist, e.g. Major Appliances |
| 品牌型号 Brand & Model | 抄机身铭牌或订单页的完整型号 Copy the full model from the nameplate or order page |
| 购买日期 Purchase Date | 格式 YYYY-MM-DD Format YYYY-MM-DD |
| 金额 Price | 实付金额，含安装费则备注 Paid amount; note it if installation is included |
| 平台 Platform | 京东 / 天猫 / 拼多多 / 线下门店 JD.com / Tmall / Pinduoduo / offline store |
| 质保期 Warranty | 按说明书与保修卡填写，区分整机与核心部件 Follow the manual and warranty card; distinguish unit from core components |
| 发票号 Invoice No. | 电子发票号或订单号 Electronic invoice or order number |

## 备注 Notes

- 燃气热水器、烟灶安装工单需单独留存，通气验收记录由燃气公司出具。Keep the installation tickets for the gas water heater and hood-hob set; the gas commissioning record is issued by the gas utility.
- 保修起算日以发票日期为准，安装日期晚于收货日期时建议同时记录两个日期。Warranty starts from the invoice date; if installation happens later than delivery, record both dates.
- 保修条款以购买时商品页与保修卡为准，本表仅作登记用途。Warranty terms follow the product page and warranty card at the time of purchase; this table is for record-keeping only.
